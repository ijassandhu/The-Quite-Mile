# CLAUDE.md — The Quiet Mile

## Project Identity

**Project name:** The Quiet Mile  
**Tagline direction:** Beyond the trail lies silence.  
**Location:** Orchard land in Chamba, Himachal Pradesh, India  
**Current stage:** Vision-stage website concept  
**Business status:** Not fully operational yet  
**Website type:** Cinematic frontend showcase / emotional brand experience  

The Quiet Mile is a rustic-modern mountain retreat concept built around silence, orchard life, foggy mountains, sunsets, stargazing, privacy, and emotional reset.

This is not a hotel website, resort platform, or generic Himachal homestay site. It should feel like a calm cinematic story about disappearing from overstimulation for a weekend.

---

## Core Product Truth

The website is not selling tourism.

It is selling:

- escape from overstimulation
- silence
- emotional reset
- disconnection
- atmosphere
- orchard life
- temporary distance from modern chaos

The ideal visitor should think:

> “I want to disappear here for a weekend.”

---

## Real Property Context

The actual property is an orchard in Chamba, Himachal Pradesh.

Current land size:

- approximately 14–15 bigha

Current fruits:

- apple
- nashpati / pear
- blueberry
- sitafal

Current access:

- no proper road connectivity
- approximately 20-minute trek / walking access

Future possibility:

- road access may improve later

Important positioning:

The walk is not a flaw to hide. It is part of the experience, but it must be communicated honestly. Do not over-romanticize inconvenience. Present it as a quiet filter for people who actually want nature, privacy, and slowness.

## Emotional Journey of Homepage

The homepage should follow this emotional progression:

1. **Stress**
   - implied through contrast with city life
   - do not show corporate imagery heavily
   - use copy that hints at exhaustion and noise

2. **Curiosity**
   - introduce the hidden orchard
   - create mystery and emotional pull

3. **Calm**
   - slow down the pace
   - use spacious sections, natural visuals, restrained copy

4. **Immersion**
   - show orchard life, fog, sunset, trails, firelight, stars

5. **Escape Fantasy**
   - help the visitor imagine staying there

6. **Inquiry**
   - invite them softly with “Plan Your Escape”
   - avoid aggressive booking language

## Component Rules

When building components:

- keep each section in its own file
- use TypeScript types for content objects
- keep components readable
- avoid giant monolithic pages
- prefer reusable layout primitives
- use responsive Tailwind classes
- use Framer Motion only where it improves atmosphere
- keep accessibility in mind
- use semantic HTML
- keep images optimized

Do not build the full website in one giant file.

---

## Styling Rules

Use Tailwind CSS.

Design principles:

- large cinematic image areas
- soft overlays
- generous spacing
- restrained text
- earthy palette
- quiet borders
- rounded elements only where natural
- no dashboard cards
- no SaaS gradients
- no glassmorphism-heavy UI unless extremely subtle

Spacing should feel slow and premium.

---

## Responsiveness Rules

Desktop:

- richer cinematic layout
- large visuals
- layered depth
- gentle parallax
- spacious sections

Tablet:

- preserve atmosphere
- reduce complexity
- maintain readable flow

Mobile:

- prioritize performance
- reduce animation
- stack sections clearly
- keep CTAs easy to tap
- avoid text over complex images if readability suffers

The mobile version should feel calm, not cramped.

---

## Accessibility Rules

Maintain:

- readable contrast
- semantic landmarks
- alt text for meaningful images
- keyboard-accessible buttons/links
- no motion that harms usability
- reduced-motion support where practical

Do not sacrifice usability for cinematic style.

---

## Performance Rules

Important because the site is image-heavy.

Use:

- optimized images
- lazy loading where suitable
- responsive image sizing
- lightweight animations
- clean component structure

Avoid:

- huge unoptimized images
- autoplay-heavy video
- WebGL unless specifically requested
- excessive animation triggers
- loading too many gallery images at once
